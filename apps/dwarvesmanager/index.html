Dwarves Manager

Run a dwarven diamond mine: recruit miners, craftsmen, bartenders and enchanters, mark out the galleries to dig, build workshops, taverns and dorms, and keep your dwarves equipped, refreshed and rested before payday drains the treasury. Seven tutorials and eight levels: the original libGDX game, ported to run right here in the browser.

Controls

Left clickUse the side panel; place dwarves, rooms and objects
Click and dragMark an area to dig (pickaxe mode) or draw a room
Right click / dragUnmark a dig area or erase a room area; remove an object or a dwarf while placing
Middle dragScroll the map
Arrow keys / screen edgeScroll the map
Mouse wheelZoom the map around the cursor; scroll the side panel lists
RRotate the object you are placing
EscBack to the main panel
S / F9Quick save / quick load
F10Game menu (save, load, options)

Start with New Game for the tutorials, or pick any level from Levels. Saves, options and best times are kept in your browser. Click inside the game first so it receives the keyboard.
